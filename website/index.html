Money Crunch

Project ID #SP-26-Green Budget App CSC 4350 · Sec 010 Spring 2026

A mobile budgeting app built to support intentional spending, habit awareness, and financial goal alignment—combining guided onboarding, bank linking, transaction sync, and visual activity views to help users understand their spending behavior.

About the project

Money Crunch helps users connect their accounts, see real transactions, and reflect on spending habits through a friendly mobile experience. The app focuses on intentional spending—not just tracking, but understanding the “why” behind each purchase.

Development approach
  • Agile sprints with weekly check-ins and shared task board
  • Mobile-first design, prototyped before implementation
  • Backend services for auth, account sync, and transactions
  • Iterative usability feedback from peer reviews
